# Greet Cam Recording

This directory contains the video recording pipeline for the greet conversation.

## Files

- **record.js** — Vendored from `/Users/mike/dev/ext/freeq/tools/greet-cam/record.js`, byte-identical. This is an untracked file with no upstream repository.

- **freeqworld.patch** — A unified diff of `client/src/app.ts` from the freeq-world repository at commit `93da7a1`. The patch updates canvas dimensions to 1920×1080 (native detail for labels and bubbles) and makes the logical viewing area dynamic based on room zoom.

## Versions

- freeqworld: `93da7a1`
- record.js: untracked
